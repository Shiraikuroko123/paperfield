# Flowloom

Flowloom 是一个浏览器原生、可静态部署的流程图与科研图版编辑器。它把手工绘图、CSV 数据可视化、论文多面板排版、结构化格式迁移、视觉参考层和 OpenAI 兼容 AI 生成统一到同一套图模型中。

- 统一平台入口：<http://127.0.0.1:8765/flowloom/>
- GitHub：<https://github.com/Shiraikuroko123/paperfield/tree/main/apps/flowloom>

当前科研版本包含精确毫米图版、Vega-Lite 可编辑统计图、十四套 LLM/VLM/VLA/具身智能论文示意图、三十八种科研原生图元、逐模板 Figure 绘制配方、数据与构图溯源、Okabe-Ito 配色、投稿前质量检查，以及可编辑 SVG、全矢量 PDF 和 300 DPI PNG 出版输出。模板依据来自 50 篇大模型论文和 50 篇具身智能论文中的 1,289 张有效 Figure；完整方法、论文清单和构图统计见 [arXiv Figure Atlas](docs/research/ARXIV_FIGURE_ATLAS.md)，开源项目与许可证取舍见 [科研绘图开源调研](docs/SCIENTIFIC_FIGURE_RESEARCH.md)。

## 两条核心论文工作流

1. **PDF 拆 SVG**：读取 PDF.js 绘制指令，把路径、基础几何和文字转换为独立 SVG 图元；每页同时保留锁定的原始 PDF 参考层。Paperfield 的“拆为 SVG”会把当前页和同源 PDF 地址送到 Flowloom，只处理所选页面。
2. **论文语义绘图**：把论文正文、页面预览、证据摘录和 canonical ref 交给 CCSwitch 所连接的已训练模型；模型只能返回结构化节点和关系，再使用科研元素库与 Gold 模板做布局。模板是构图先验，不是论文事实来源；没有证据的元素必须标记为推断。

Flowloom 当前负责模型推理、结构约束、证据记录和可编辑渲染，不在浏览器内训练模型。后续训练或微调应产出兼容 OpenAI Chat Completions 的模型端点，并遵守本仓库中的结构化输出契约。

## 最高精度能保证到什么程度

不能用一个百分比概括所有格式。可保证的最高等级取决于源文件是否包含图元结构：

| 场景 | 最高可保证等级 | 明确边界 |
| --- | --- | --- |
| Flowloom JSON v2 在同版本应用中导出再导入 | 字段级结构无损往返 | 页面、图层、分组、节点、连线、坐标、尺寸、旋转和样式可恢复；浏览器字体渲染仍可能存在平台差异 |
| 基础 SVG | 图元级结构编辑 | `rect`、`circle`、`ellipse`、`line`、`polyline`、`polygon`、`path`、`text` 会成为独立可编辑对象，支持继承样式、基础单位和嵌套变换 |
| 高级 SVG | 混合保真 | 渐变、滤镜、蒙版、裁剪、CSS、动画、`use` 等会生成可编辑近似，并在独立的隐藏锁定图层保留完整原图供对照 |
| PNG、JPG、WebP | 原貌视觉参考 | 原稿作为一个整体对象移动和缩放，不谎称内部元素可独立编辑 |
| PDF | 结构、混合或视觉保真 | 基础路径、几何和文字会成为独立可编辑 SVG 图元；位图、裁剪、复杂字体与不支持的效果保留在锁定参考层。Paperfield 桥接只处理当前页，直接导入文件则逐页处理 |
| Mermaid、DOT、PlantUML、CSV | 语义结构保真 | 节点和关系可编辑，布局和字体不承诺与其他软件逐像素相同 |
| draw.io、BPMN、Excalidraw、VSDX | 结构或混合保真 | 135 个内置图形通过 draw.io 往返时保留内部图形 ID，draw.io 页面、图层和分组可恢复；外部专有母版、自由曲线、插件图元和复杂效果仍可能近似 |
| AI 重建图片或文档 | 可编辑近似 | AI 输出具有不确定性，不能承诺固定百分比或逐像素一致 |

因此，当前能够诚实保证的最高精度是：

- 要“完全可编辑且无损往返”，使用 Flowloom JSON v2。
- 要“原貌不被错误重建”，使用视觉参考导入，原稿作为整体对象保留。
- 导入 SVG 后，基础图元可直接编辑；如果状态为“混合保真”，在右侧“图层”中打开“原图参考”进行视觉核对。
- 对缺少结构信息的图片或普通 PDF，无法同时保证逐像素一致和每个元素独立可编辑。

画布几何方面，尺寸输入可稳定控制到 `1 CSS px`；拖动坐标内部使用浮点数。默认开启 `12 px` 网格吸附，关闭底部网格按钮后可自由定位。需要缩放无损的发布文件时优先导出 SVG。

## 科研绘图工作台

顶部单击“科研”，手机端从“菜单”选择“打开科研绘图工作台”。工作台分为四个任务：

### 1. 多面板科研图版

1. 在“图版”中设置宽度、高度、目标 DPI、行列、页边距和面板间距。
2. 可从 89 mm 单栏、180 mm 双栏、方形、A4 内容区和 16:9 常用尺寸开始，也可输入任意 `20–500 mm` 尺寸。
3. 应用后，白色背景建立精确导出边界，虚线面板框只用于编辑并在导出时隐藏。
4. A/B/C 面板标签是独立矢量文字，可移动、缩放、改字和改色。

这些预设只是常见起点，不代表 Nature、Science 或任何期刊的认证规格。期刊指南和不同栏目要求会变化，投稿前必须核对目标期刊当期说明。

### 2. CSV 数据转可编辑图表

1. 切换到“数据图表”，粘贴 CSV/TSV/分号表格，或上传 `.csv`、`.tsv`、`.txt`。
2. 选择散点、折线、柱状、箱线、热图或误差线，并映射 X、Y、颜色/分组和误差字段。
3. 填写坐标单位；误差线图还应明确 SD、SEM、置信区间或其他统计定义。
4. 右侧 Vega-Lite 预览实时更新。插入后默认只选择图表根组，方便整体移动；坐标轴、网格线、文字、图例和数据标记仍是独立 SVG 图元。
5. 选中图表根组后，右侧“科研数据来源”显示文件、图表类型、字段映射、引擎和生成时间，并可下载原始 CSV 与 Vega-Lite JSON 规范。

图表根组会保存原始数据、字段映射、单位、不确定性定义、完整规范和引擎版本。所有转换在浏览器本地完成，不会把 CSV 上传到服务器。分类颜色使用 Okabe-Ito 色盲友好色板；散点和折线还会使用点形或线型作为冗余编码。

### 3. LLM / VLM / VLA / 具身智能论文示意图

1. 切换到“论文示意图”，从十四套结构原型中选择多模态基础模型、视觉语言桥接、VLA 机器人策略、提示智能体、具身闭环、训练部署、LLM 全阶段训练、MoE 路由、RAG 工具智能体、推理轨迹、机器人数据采集、世界模型展开、Sim-to-Real 或多机体策略。
2. 选择柔彩分区、克制科技或黑白友好样式，并设置精简、标准或详细结构密度。
3. 图中文字可在英文和中文间切换；图题与 VLM/LLM/策略主干名称可以直接改写。
4. “Figure 绘制配方”会给出阅读顺序、视觉中心、版式区域、必要元素、箭头/颜色语义、具体绘制步骤和投稿前检查；右侧预览同时显示实际对象、连接数量和参考的 arXiv Figure。
5. 插入后，分区、输入模态、编码器、投影器、token 流、主干、动作专家、损失、机器人环境和反馈箭头都是独立原生对象，可逐项移动、缩放、改字、改色、重连和删除。
6. 选中最外层图框后，右侧“论文构图来源”会显示模板或 AI 生成方式、样式、密度、参考 arXiv ID 和生成引擎，并可下载构图元数据。

这些模板提炼公开论文的共同信息组织方式，图形和配色由 Flowloom 重新设计；没有复制论文原图、照片或品牌资产。

### 4. 投稿前质量检查

“质量检查”会报告：未设置物理尺寸、对象或连接标签越界、小于 6 pt 的文字、小于 0.6 pt 的线宽、文字溢出、对象重叠、阶段标题碰撞、错误端口方向、连线共线重叠/穿越/非必要交叉、低对比、位图有效 DPI 未知、缺失构图来源、无来源结果数值、数据契约不完整、图表缺少原始数据、误差线含义缺失和超大位图输出。每条结果都说明规则和涉及对象数量；6-7 pt 文字与 0.6-0.8 pt 线宽会作为复核警告。

检查结果是可解释的预检，不是期刊合规证明，也不能替代统计方法、图像完整性和论文内容审查。

### 5. 科研尺寸导出

- SVG：科研页面使用原生 `path`、`rect`、`text`、`image` 等图元，写入 `mm` 物理尺寸和来源摘要，不包含 HTML `foreignObject`。这是当前首选的可缩放投稿格式。
- PNG：按 `毫米 ÷ 25.4 × DPI` 生成精确像素尺寸并写入 DPI 元数据，透明背景可保留。
- PDF：页面宽高使用毫米，节点、连线、文字和图元均保留为矢量对象；随项目提供的 Noto Sans SC 字体会嵌入 PDF。仍应在投稿前用目标出版社推荐的 PDF 工具复核字体、透明度和印刷效果。
- Flowloom JSON：保留页面规格、完整 CSV、图表规范、分组、图层和全部可编辑数据，是主工程备份格式。

## 组件开发模式

统一产品请从仓库根目录运行 `scripts\run-platform.ps1`，并访问
<http://127.0.0.1:8765/flowloom/>。下面的 `5173` 入口只用于单独开发
Flowloom 组件，需要 Node.js 20 或更高版本。

### 方法一：双击启动

双击项目根目录的 `start-flowloom.cmd`：

1. 首次运行会自动安装依赖。
2. 脚本会启动本地服务器并打开浏览器。
3. 默认地址是 <http://127.0.0.1:5173/>。
4. 启动窗口必须保持打开；按 `Ctrl+C` 或关闭窗口即可停止服务。

### 方法二：PowerShell 启动

```powershell
cd G:\ps\paper-scout\apps\flowloom
npm install
npm run dev -- --host 127.0.0.1 --port 5173
```

终端出现 `Local: http://127.0.0.1:5173/` 后再用浏览器打开该地址。以后已经安装过依赖时，只需要运行最后一条命令。

如果 `5173` 被占用，可以改用其他端口：

```powershell
npm run dev -- --host 127.0.0.1 --port 5174
```

然后访问 <http://127.0.0.1:5174/>。

## 完整使用方法

### 1. 新建和编辑图形

1. 从左侧图形库单击图形，或把图形拖到画布。搜索支持中文名称、英文标准名和用途关键词。
2. 双击非图片节点可直接修改文字。
3. 拖动节点四周的连接点建立连线。
4. 单击节点后，可精确修改 X/Y、宽高、字号、字重、水平/垂直对齐、填充、边框、透明度、层级与锁定状态。
5. 单击连线后，可修改折线/直线/曲线路径、实线/虚线/点线、线宽、颜色、起点与终点箭头，并可反转方向。
6. 多选节点后可进行左对齐、居中、右对齐、顶部/底部对齐、按实际边界等距分布、分组和批量修改外观。
7. 方向键按 `1 px` 微调所选对象，`Shift+方向键` 按 `10 px` 移动。
8. 未选择对象时，右侧面板可执行纵向或横向自动布局。
9. 底部控制条用于缩放、适合画布、网格吸附和缩略图开关。

图形库当前包含 135 个可编辑图形，所有素材库预览与画布图元共用同一套 SVG 几何：

| 分类 | 数量 | 内容 |
| --- | ---: | --- |
| 标准流程图 | 29 | 终止符、处理、判断、输入/输出、文档与多文档、预定义过程、准备、手工输入、人工操作、各类存储、连接符、合并/提取/排序/校对、汇总/或连接、纸带、穿孔卡片、循环界限、批注范围等 |
| BPMN 2.0 | 25 | 开始/中间/结束与消息/定时/错误/信号事件，多类任务与活动，五类网关，数据对象、数据存储、参与者池和事务 |
| UML | 15 | 参与者、用例、类、包、组件、状态、接口、对象、制品、部署节点、活动判断、终止状态、生命线和注释 |
| 实体关系图 | 8 | 实体、弱实体、联系、标识联系、属性、主键属性、多值属性和数据表 |
| 系统架构 | 10 | 服务、API、服务器、数据库、缓存、消息队列、对象存储、负载均衡、防火墙和客户端 |

| 基础图形 | 7 | 矩形、圆角矩形、椭圆、三角形、六边形、云、标注气泡 |
| 容器与标注 | 3 | 便笺、分组容器、泳道 |

手机和平板上，左右面板会变成互斥抽屉。打开图形库会自动关闭属性面板，反之亦然。

### 2. 页面、图层和分组

1. 画布下方的页面栏支持新建、重命名、复制、删除和切换页面。
2. 右侧切换到“图层”后，可以新建、重命名、排序、隐藏、锁定和删除图层，也可以把所选对象移动到指定图层。
3. 图层对象树支持单独选择、显示、隐藏、锁定和解锁对象。
4. 选择两个或更多节点后按 `Ctrl+G` 建立真正的父子分组；选择分组后按 `Ctrl+Shift+G` 解组。
5. 页面、图层、分组以及导入/新建文档都进入同一套文档级撤销历史；切换页面不会清空历史。

### 3. 选择、移动和恢复操作

- 顶部箭头为选择工具，手掌为平移工具。
- 选择工具下可以框选；按住 `Shift` 可以多选。
- 按住空格可临时拖动画布。
- 顶部撤销/重做按钮可恢复编辑操作。
- 草稿会自动保存到当前浏览器的 localStorage。
- 大型图片或多页 PDF 可能超过浏览器存储限额，此时应立即导出 Flowloom JSON 备份。

### 4. 导入文件

1. 单击顶部“导入”。
2. 选择文件，或把单个文件拖入导入窗口。
3. 等待解析结果，并查看“结构保真 / 混合保真 / 视觉保真”标记和警告。
4. 单击“导入到画布”。
5. 导入后检查连接关系、字体、专有图形和页面尺寸，再继续编辑。

当前支持：Flowloom JSON/YAML、draw.io XML、Mermaid、Graphviz DOT、PlantUML、BPMN 2.0、Excalidraw、CSV、基础 Visio VSDX、SVG、PNG、JPG、WebP 和 PDF。

SVG 导入后可以直接选择、移动、缩放、旋转、改色和调整描边；SVG `<text>` 支持双击修改文字。高级效果触发“混合保真”时会创建两个图层：默认活动的“可编辑图元”和隐藏锁定的“原图参考”。

### 5. 使用代码绘图

1. 桌面端单击顶部“代码”；手机端打开“菜单”，选择“使用代码绘制流程图”。
2. 选择 Mermaid、Graphviz DOT 或 PlantUML。三种格式会分别保留当前浏览器会话中的草稿。
3. 输入或粘贴代码，右侧会实时显示解析状态、节点/连线数量和结构预览。
4. 出现“兼容提示”时先检查未识别语句；出现“语法错误”时，生成按钮会禁用且现有画布不会改变。
5. 单击“生成到画布”或按 `Ctrl+Enter`。结果是独立节点和连线，可以继续移动、改字、改色、连接和删除。

当前代码工作台面向可编辑结构转换，支持范围如下：

- Mermaid：`flowchart` / `graph` 流程图、常用节点形状、带标签连线、虚线和加粗连线。
- Graphviz DOT：`digraph`、节点 `label` / `shape`、有向边标签和 `rankdir` 横纵布局。
- PlantUML：活动图的 `start`、`stop`、动作、`if / else / endif` 分支和单行注释。

生成会作为一次可撤销的文档操作替换当前页。工作台不会把代码先渲染成图片，因此生成后的节点可以独立编辑；尚未覆盖的语言指令会显示兼容提示，不能据此承诺完整 Mermaid、DOT 或 PlantUML 语法的逐项等价转换。

### 6. 使用 AI 生成流程图和论文示意图

1. 单击顶部“AI 生成”。
2. 普通流程选择业务场景；论文图选择“大模型 / 多模态论文示意图”“VLA / 具身智能系统图”或“训练、推理与数据闭环”。
3. 可以添加最多 8 个文本、数据或图片附件。
4. 展开“接口设置”，填写 `Base URL`、模型名称和可选的 `API Key`。
5. 单击“生成流程图”或“生成论文示意图”。生成结果会进入画布，并可继续手工编辑。

论文场景使用独立结构协议：AI 必须返回分区、模块角色、画布坐标、尺寸、颜色、线型和反馈路径，而不是位图。模型、提示词和附件名称会写入最外层图框的来源元数据；API Key 不会进入图形文件。

更稳定的提示词应明确包含：起点、终点、步骤、决策条件、失败路径、参与角色和布局方向。例如：

```text
生成一个横向的软件发布审批流程。包含提交申请、自动化检查、负责人审批、灰度发布、指标判断、全量发布和回滚路径。每个判断必须包含“是/否”分支。
```

论文示意图示例：

```text
绘制一个横向 VLA 机器人策略图：相机观察、语言指令和本体状态分别编码后形成统一 token 序列，进入 VLM 主干和动作专家，输出 16 步动作块。显示安全过滤、机器人环境以及回到观察端的虚线反馈回路。用黑白友好样式，区分训练损失和推理路径。
```

### 7. 配置 CCSwitch

Flowloom 调用的是浏览器可访问的 OpenAI Chat Completions 兼容 HTTP 接口。CCSwitch 只切换本机 CLI 配置时，浏览器不能自动读取它；必须确认当前提供方实际暴露了 HTTP 端点。

- `Base URL` 示例：`http://127.0.0.1:3000/v1`
- `模型`：填写该端点实际提供的模型 ID
- `API Key`：端点不要求时可以留空
- “在此浏览器保存 Key”默认关闭；不要把密钥写进 `VITE_*` 环境变量

也可以创建 `.env.local`：

```dotenv
VITE_AI_BASE_URL=http://127.0.0.1:3000/v1
VITE_AI_MODEL=你的模型ID
```

修改 `.env.local` 后必须重启 Flowloom。若出现“无法访问 AI 接口”，依次检查端点是否运行、URL 是否包含正确的 `/v1`、模型 ID、CORS 和浏览器网络限制。

从 GitHub Pages 的 HTTPS 页面访问本机 HTTP 接口时，可能受混合内容、CORS 或 Private Network Access 限制。正式部署建议使用允许目标域名访问的 HTTPS AI 网关。

## 常见问题

### `127.0.0.1:8765/flowloom/` 打不开

统一平台没有运行或构建产物尚未生成。在仓库根目录执行 `scripts\run-platform.ps1`；首次启动会自动构建 Flowloom 与课程站。

### 导入结果和原软件外观不同

先看底部保真状态。结构保真表示图关系可靠，不等于字体和渲染引擎逐像素一致；混合保真表示部分专有能力被近似；视觉保真表示原稿整体保留而未拆图元。

### 草稿保存失败

浏览器 localStorage 容量有限。多页 PDF 和大图片应及时导出 Flowloom JSON；必要时先压缩来源文件。

### GitHub Pages 页面能打开但 AI 失败

静态页面本身正常，但 AI 端点不可从公网 HTTPS 页面访问。需要启用 CORS、HTTPS 和相应网络访问头，或使用部署在公网的兼容网关。
