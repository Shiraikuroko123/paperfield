# Flowloom 科研绘图开源调研

更新时间：2026-07-28。Star 数来自当日 GitHub API 快照，只用于衡量社区规模，不代表技术质量或许可证授权范围。

## 调研结论

科研绘图不是“多放一些实验室图标”。面向论文的工具至少要同时处理数据诚信、精确物理尺寸、可编辑矢量图、多面板排版、颜色可访问性、来源追溯和出版前检查。Flowloom 采用分层路线：

1. Vega-Lite/Vega 负责数据到 SVG 的可复现语法和统计图形。
2. Flowloom 的 SVG 解析器把生成结果拆为独立路径、文字和几何图元。
3. 页面保存毫米尺寸、目标 DPI、面板网格和导出边界。
4. 图表根组保存原始 CSV、字段映射、单位、误差定义、图表规范和引擎版本。
5. 自动检查只报告可解释的问题，不宣称通过 Nature、Science 或任何期刊认证。

## arXiv 大模型与具身智能论文构图调研

本轮不是只看少量代表作，而是运行可复现脚本 `scripts/research-arxiv-figures.mjs` 建立两个各 50 篇的设计语料组。大模型组覆盖架构与扩展、对齐微调、推理与智能体、检索记忆、多模态、效率与长上下文；具身智能组覆盖 VLA 通用策略、操作、导航智能体、世界模型与规划、数据集基准、机器人平台。候选来自 arXiv API 与人工种子，使用 Semantic Scholar 引用快照辅助分层排序，再从 ar5iv（失败时回退 arXiv HTML）提取 Figure、caption 和图片地址。访问日期为 2026-07-28。

最终两组均为 50 篇，其中各 49 篇成功提取 Figure：大模型组 1,448 个，具身智能组 1,155 个，合计 2,603 个。自动标签只由 caption 关键词生成，随后结合本地 contact sheet 人工检查；它是产品设计语料，不是系统综述或论文质量排名。完整论文、Figure、caption、来源 URL、构图标签与统计位于 [arXiv Figure Atlas](research/ARXIV_FIGURE_ATLAS.md)，机器可读语料位于 `docs/research/arxiv-figure-corpus.json`。

## 当前版本已经落地

- 精确毫米宽高、72–1200 DPI、行列、边距、间距和 A/B/C 面板标签。
- 单栏、双栏、方形、A4 内容区和 16:9 常用起点；这些不是期刊认证预设。
- CSV/TSV/分号表格解析，支持引号、缺失值和数值字段识别。
- 散点、折线、柱状、箱线、热图和误差线。
- Okabe-Ito 分类色板；散点用颜色+点形，折线用颜色+线型/点形进行冗余编码。
- Vega-Lite SVG 拆解为独立 `path`、`rect`、`text` 等图元，并包装为可整体移动的图表组。
- 图表保存原始数据、映射、单位、不确定性说明、规范和引擎版本。
- 检查最小字号、最小线宽、透明度、图版越界、位图有效 DPI 未知、原始数据缺失和误差含义缺失。
- 科研页面按目标毫米尺寸裁切；PNG 按目标 DPI 计算像素并写入分辨率元数据，PDF 使用毫米页面和目标 DPI 图像，SVG 写入 `mm` 物理尺寸。
- 三十八种科研原生图元：观察与机器人场景、Token/张量、Transformer 与特征表示、网络层/数据集堆叠、冻结/可训练模块、相机与多类机器人、任务物体、目标区域、接触点、动作轨迹与动作块、体素网格、坐标系、时间步序列、概率/不确定性、指标/消融/决策、偏好样本、数据筛选、发布门、科研图例、公式和局部放大。
- 十四套论文系统示意图：六套基础原型，以及由 100 篇语料新增的 LLM 训练、MoE 路由、RAG 工具智能体、推理轨迹、机器人数据采集、世界模型展开、Sim-to-Real 和多机体策略。
- 每套模板都包含可见的 Figure 绘制配方：版式区域、阅读顺序、视觉中心、必要元素、箭头/颜色语义、逐步绘制方法和投稿检查，不再只提供散装图元。
- 每套示意图支持柔彩分区、克制科技、黑白友好三种语义样式，精简/标准/详细三档结构密度，以及中英文图中文字。
- 示意图中的分区、模块、token、数据、损失、动作、机器人环境和全部箭头都是原生节点/连线；插入后可独立移动、改字、改色、缩放和重连。
- CCSwitch/OpenAI 兼容 AI 在论文场景下使用单独的结构协议，可生成画布坐标、模块角色、分区、尺寸、线型与反馈回路；不会请求或返回位图作为最终结果。
- 模板根对象保存构图模板、样式、密度、主干名称和参考 arXiv ID；AI 根对象保存模型、提示词和附件名称，不保存 API Key。

## 后续工程顺序

1. 引入 Cytoscape.js 网络/通路工作台，并提供 GraphML、SIF、CX、GEXF 和常见生物网络格式适配器。
2. 在现有论文示意图原生语法之上增加文本 DSL，并评估 Penrose 子集或兼容适配层。
3. 建立逐资产许可证清单后加入生命科学、化学、医学和实验装置图标。
4. 增加 LaTeX/MathJax 公式、比例尺、显著性标注、图例生成器和共享样式。
5. 增加 EPS、真正的矢量 PDF、TIFF/CMYK 工作流；浏览器无法可靠实现的出版转换交给可选本地 CLI，而不在静态站点中伪装支持。
6. 建立期刊要求的可更新配置库，只显示“与某次指南规则对照”，不显示“官方认证”。

## 许可证准则

- MIT、BSD、ISC 等依赖必须保留其许可证文件与 npm 锁定版本。
- GPL/AGPL 项目只做公开能力对标，除非项目整体许可策略明确改变。
- 图标和插图的许可证按资产而不是按网站仓库判断。
- CC BY 资产必须在图形元数据和导出清单中保留作者、来源、许可证、链接与修改记录。
- 任何未知许可资产默认不可进入内置商用素材库。
