# 术语表

## A-D

**Advantage**<br>
动作或回答相对某个 baseline 好多少的估计，用于控制 policy gradient 的方向和方差。

**All-Reduce**<br>
在多个 rank 间聚合并把结果分发回所有 rank 的 collective，常用于同步梯度或统计量。

**Autograd**<br>
根据前向运算图自动计算梯度的机制。

**BF16**<br>
具有 8 位指数、7 位显式尾数的浮点格式，指数范围接近 FP32。

**Checkpoint**<br>
模型参数以及恢复训练所需的优化器、调度器、步数、RNG 和数据状态快照。

**Causal mask**<br>
阻止当前位置读取未来 token 的 attention mask。

**Cross-entropy**<br>
用模型分布编码目标分布的期望信息量；one-hot 标签下等于目标类负 log-prob。

**Data parallelism (DP)**<br>
不同设备处理不同数据，随后同步梯度或参数分片。

**Decode**<br>
自回归生成中逐 token 推理的阶段，通常复用 KV cache。

**DPO**<br>
Direct Preference Optimization，用 chosen/rejected 对直接优化相对偏好目标的方法族。

## E-K

**Effective tokens/s**<br>
真正进入目标 loss 的有效 token 吞吐，不包含 padding、被 mask 位置或无效重算。

**EOS**<br>
End of sequence，表示序列结束的特殊 token。

**FSDP**<br>
Fully Sharded Data Parallel，将参数、梯度和优化器状态按 rank 分片的数据并行实现。

**GRPO**<br>
Group Relative Policy Optimization，用同一 prompt 的一组回答构造相对 advantage 的方法族。

**GQA**<br>
Grouped-Query Attention，多组 query head 共享较少的 KV head，以降低 KV cache。

**Importance ratio**<br>
当前策略与行为策略对同一样本的概率比，常在 log 域差分后指数化。

**ITL**<br>
Inter-token latency，相邻输出 token 之间的延迟。

**KL divergence**<br>
两个概率分布差异的非对称度量；方向和估计方法必须明确。

**KV cache**<br>
保存每层历史 token 的 key/value，避免 decode 时重复计算。

## L-R

**Label mask**<br>
决定哪些 token 位置进入训练 loss 的 mask。

**Logit**<br>
softmax 之前的未归一化分数。

**Log-prob**<br>
概率的自然对数，长序列中通过求和避免概率乘积下溢。

**LoRA**<br>
用低秩矩阵表示权重更新、冻结基座参数的参数高效微调方法。

**MoE**<br>
Mixture of Experts，通过 router 为 token 选择部分 expert 的稀疏模型结构。

**PPO**<br>
Proximal Policy Optimization，以 surrogate objective 和 clip/KL 等机制限制策略更新的方法族。

**Prefill**<br>
推理中一次处理完整 prompt 并建立 KV cache 的阶段。

**Reference policy**<br>
用于定义 KL 约束或偏好基准的固定策略。

**Reward hacking**<br>
策略提高代理 reward，却违背真实任务目标或利用评估漏洞。

**Rollout**<br>
策略针对 prompt 采样的回答，以及 log-prob、reward、版本等训练元数据。

**RoPE**<br>
Rotary Position Embedding，通过旋转 query/key 子空间编码位置信息。

## S-Z

**SFT**<br>
Supervised fine-tuning，在指令/回答样本上继续优化 token-level 监督 loss。

**Staleness**<br>
样本生成策略与训练消费时当前策略之间的版本或分布距离。

**Tensor parallelism (TP)**<br>
把同一层的矩阵计算沿维度切分到多个设备。

**Test-time scaling**<br>
不更新模型参数，通过更多采样、搜索、验证或工具调用提高推理成功率。

**Token**<br>
Tokenizer 词表中的离散单元，不等于字、词或字符。

**TTFT**<br>
Time to first token，从请求到首个输出 token 的延迟。

**World size**<br>
参与某个分布式通信组的进程/rank 数量。
