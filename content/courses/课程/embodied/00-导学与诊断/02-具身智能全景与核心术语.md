# M0.2 专题：具身智能全景与核心术语

## 一、一句话定义

**具身智能（Embodied AI）= 智能体通过身体与物理世界交互，在感知-决策-行动闭环中完成任务的智能。**

对照记忆：LLM 是"离身智能"——输入输出都是符号（文字），不接触物理世界。具身智能的输出是**动作**，动作会改变世界，改变后的世界又成为新的输入。这个闭环是一切难点的来源。

## 二、为什么难：三个核心矛盾

**1. Moravec 悖论**：对人难的（下棋、微积分）对 AI 容易；对人容易的（叠衣服、拧瓶盖）对 AI 极难。感知运动能力是几亿年进化的产物，符号推理只有几千年。

**2. 数据矛盾**：GPT 靠互联网万亿 token 训练，但互联网上**没有机器人动作数据**。动作数据只能靠遥操作一条条采（贵、慢），或仿真生成（有 Sim2Real 差距）。这是当前具身智能最大的瓶颈，没有之一。

**3. 误差代价矛盾**：LLM 说错话可以重来，机器人打碎杯子不能撤销。物理世界不容许"采样重试"，对可靠性要求高一个量级。

## 三、技术栈分层（复试画图利器）

```
任务指令 "把桌上的苹果放进碗里"
   ↓
[大脑层] 任务理解与规划        ← LLM/VLM 的主场
   ↓
[策略层] 视觉+指令 → 动作序列   ← VLA / 模仿学习 / RL 的主场（研究最热区）
   ↓
[控制层] 动作 → 关节力矩       ← 经典控制 / RL 控制器
   ↓
[本体层] 电机、传感器、机械结构  ← 硬件
```

当前学术竞争集中在**策略层**：怎么把"看到的+听到的"映射成"该做的动作"。

## 四、范式演进（30 秒讲清领域史）

1. **经典控制时代**（~2015 前）：人工建模+规划，精确但脆弱，换个场景就失效
2. **深度 RL 时代**（2016-2021）：仿真里试错学习，运动控制（四足行走）大成功，但操作任务奖励难设计
3. **模仿学习时代**（2021-2023）：人遥操作示范、模型模仿（ACT、Diffusion Policy），操作任务的突破口
4. **基础模型时代**（2023- ）：VLA——用预训练视觉语言模型做底座，海量机器人数据微调，追求"一个模型干所有活"（RT-2 → OpenVLA → π0 → GR00T）
5. **正在发生**（2025- ）：世界模型提供数据与仿真 + VLA 提供策略的闭环；跨本体泛化

## 五、核心术语表（复试黑话，必须秒懂）

| 术语 | 一句话解释 |
|---|---|
| **VLA** | 视觉-语言-动作模型：输入图像+指令，直接输出机器人动作 |
| **端到端** | 感知到动作一个网络搞定，不手工设计中间模块 |
| **遥操作 (Teleoperation)** | 人远程操控机器人做示范，采集训练数据的主要方式 |
| **模仿学习 / BC** | 直接模仿人类示范数据，Behavior Cloning 是最简形式 |
| **Sim2Real Gap** | 仿真里训得好、真机上失效的差距（物理、视觉差异所致） |
| **域随机化** | 训练时随机扰动仿真参数，逼策略学得鲁棒，跨过 Sim2Real |
| **跨本体 (Cross-embodiment)** | 一个模型驱动不同形态的机器人（不同臂、不同手、人形） |
| **灵巧操作 (Dexterous)** | 多指手完成精细操作，操作任务的珠峰 |
| **Affordance** | 物体"可被怎样操作"的属性（杯柄可握、按钮可按） |
| **世界模型** | 学习预测"如果我做这个动作，世界会变成什么样"的模型 |
| **Scaling Law（具身版）** | 数据/模型规模换能力——在机器人领域是否成立仍是开放问题 |

## 六、复试级问答（先自答，再看要点）

**Q1：具身智能和 LLM Agent 的本质区别是什么？**
要点：交互对象不同（物理世界 vs 符号世界）→ 三个后果：①数据不能从互联网白嫖，必须交互采集；②动作不可撤销，可靠性要求高；③受物理定律和实时性约束。LLM Agent 调用的工具是 API，具身智能的"工具"是自己的身体。

**Q2：为什么机器人不能像 GPT 一样靠海量数据大力出奇迹？**
要点：核心是数据。①可直接执行的机器人动作数据无法像文本那样从互联网批量获得；②遥操作采集需要人、设备、场地和重置；③数据异构（不同机器人、传感器、坐标系）难以直接合并。注意：trajectory 与 token 是不同统计单位，不能用两者计数直接计算“相差几个数量级”。领域主要探索共享数据集、仿真/世界模型合成和人类视频预训练等路线。

**Q3：你认为当前具身智能最大的瓶颈是什么？**
要点：可答"数据"（最安全、证据最足），但要展现层次：数据量 → 数据质量与多样性 → 评测（各家 demo 惊艳但缺乏可比 benchmark，泛化性存疑）。加分句：'demo-to-product gap'——实验室 90% 成功率距离产品要求的 99.9% 还差两个 9，而这两个 9 可能比前面 90% 更难。
