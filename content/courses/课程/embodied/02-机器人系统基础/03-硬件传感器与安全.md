# M2.3 主干：硬件、传感器与安全

## 学习目标

学完本章，你应能看懂机器人基本硬件链路，为任务选择传感器和执行器，识别同步、标定、饱和与失效风险，并写出第一次上真机的安全流程。

## 6.1 本体不是模型的外设

具身系统的能力上限受身体限制：自由度、工作空间、负载、带宽、回差、刚度、传感器视野和散热都会改变可学策略。相同 VLA 换一台机器人，动作空间、延迟和动力学全部变化。

常见形态：固定机械臂、双臂、轮式移动机械臂、四足、人形和灵巧手。形态选择应由任务约束决定，而不是由热度决定。

## 6.2 执行器

| 执行器 | 特点 | 常见场景 |
|---|---|---|
| 伺服电机+减速器 | 控制成熟、力矩密度高 | 机械臂、人形 |
| 直驱/准直驱 | 回差小、力控好、冲击耐受 | 四足、动态关节 |
| 液压 | 功率密度高 | 重载与高动态平台 |
| 气动/软体 | 柔顺、安全 | 软体机器人、夹具 |

关键指标：连续/峰值力矩、速度、回差、摩擦、编码器分辨率、热限制和通信频率。峰值力矩不能长期使用，训练出的高频抖动可能触发过热或缩短寿命。

## 6.3 传感器

- 编码器：关节位置；速度常由差分估计，因此更噪。
- IMU：角速度和线加速度；存在偏置漂移。
- RGB/RGB-D/双目：环境视觉；受曝光、反光、遮挡影响。
- 力矩/六维力传感器：接触力；需要零偏和坐标变换。
- 触觉：接触位置、压力、滑移；标定和耐久仍是挑战。
- 麦克风：语音和事件声；不是所有任务都需要。

选择传感器先问：任务状态是否可观测？需要的精度和频率是多少？传感器失败时系统应如何降级？

## 6.4 标定与同步

标定包括：

- 相机内参和畸变；
- 相机到基座/末端的外参；
- 关节零位和连杆参数；
- 力传感器零偏、尺度和安装方向；
- 时间偏移。

多传感器数据必须有统一时钟或可估计时间偏移。相机 30 Hz、控制 100 Hz 时，不能简单按数组下标对齐。需要时间戳、插值，并记录延迟。

## 6.5 控制与计算链

```text
传感器 -> 驱动 -> 中间件 -> 状态估计 -> 策略/规划
       -> 安全过滤 -> 轨迹/控制器 -> 总线 -> 电机驱动器
```

高层模型常运行在 GPU 计算机，低层闭环运行在实时控制器或电机驱动器。两者通信中断时，低层必须有超时保护，而不是继续执行最后一个速度命令。

## 6.6 安全分层

安全不能只靠一句“设置急停”：

1. **机械层**：吊架、软包、限位、降低负载、清空工作区。
2. **电气层**：独立急停切断使能，保险与电流限制。
3. **固件层**：位置、速度、力矩、温度和通信超时保护。
4. **控制层**：动作裁剪、碰撞检查、软限位、异常状态机。
5. **流程层**：低速单关节测试、双人复核、日志、回退方案。

急停应独立于运行学习策略的电脑。真机首次部署时，操作者的手应在急停附近，但人不应站在机器人可能扫过的区域内。

## 6.7 第一次上真机流程

```text
1. 不上电检查模型、关节方向、零位、单位和限位。
2. 吊架/支撑下，只使能一个关节，使用低增益和小动作。
3. 对拍观测：真机静止姿态与仿真/可视化是否一致。
4. 验证急停、通信超时和动作限幅确实触发。
5. 先运行手写安全轨迹，再运行策略。
6. 策略先降速、缩小动作范围、空载运行。
7. 每次扩大范围只改一个条件，并保存日志。
```

## 6.8 数据记录

至少记录：单调时钟时间戳、原始传感器、估计状态、策略原始输出、安全层后输出、实际命令、错误码、急停/限幅事件和软件版本。

只录视频无法复盘控制问题；只录数值又可能看不出遮挡和碰撞。二者都需要。

## 6.9 自测题

1. 峰值力矩为什么不能当持续力矩使用？
2. 为什么编码器位置准确不代表速度估计也准确？
3. 相机和动作时间偏移 100 ms 会怎样污染模仿学习数据？
4. 通信中断时，为什么“保持最后一个命令”可能危险？
5. 写出一个至少包含机械、电气、固件、控制和流程层的安全清单。
