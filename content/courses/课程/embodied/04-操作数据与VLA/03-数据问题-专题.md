# M4.3 专题：具身智能的数据问题

> 锚点论文：Open X-Embodiment（2023，34 个实验室联合）；延伸：UMI、MimicGen、AgiBot World

## 一、把数字刻在脑子里

- GPT 类模型：**万亿级** token，互联网免费
- Open X-Embodiment（全球 34 实验室凑的最大共享库）：**百万级**轨迹
- 一条遥操作轨迹成本：分钟级人工 + 场地 + 设备

**机器人监督数据稀缺，但不能用 trajectory 与 token 的计数直接算数量级差。** 更有意义的比较是总小时/控制步、任务与场景覆盖、失败和恢复比例、动作维度以及采集成本。正因为高质量、多样化机器人数据昂贵，“怎么搞数据”本身就是重要研究问题。

## 二、数据金字塔（Physical Intelligence / NVIDIA 共识框架）

```
        ▲ 真机遥操作数据   ← 最准最贵最少（金字塔尖）
       ▲▲ 仿真/合成数据    ← 便宜量大，有 Sim2Real 税
      ▲▲▲ 人类视频        ← 海量（YouTube/Ego4D），但没有动作标签
     ▲▲▲▲ 互联网图文       ← 无限，提供语义先验（VLA 底座的来源）
```

训练策略 = 用下层打底座（预训练），上层做对齐（微调）。理解了金字塔，就理解了所有 VLA 的训练配方。

## 三、每一层的关键工作

**真机遥操作层**
- ALOHA：双臂主从遥操作，精细任务示范的标杆
- **UMI**：手持夹爪+GoPro，人拿着满世界采数据，不需要机器人在场——"数据采集设备化"的代表巧思
- **AgiBot World**（智元）：百台机器人的"数据工厂"，百万级轨迹开源，中国式规模化路线
- SO-ARM100 + LeRobot：把遥操作采数据降到百元级门槛（你复现冲刺会用到这个生态）

**仿真/合成层**
- **MimicGen**：一条人类示范，按物体位姿把轨迹分段重排+插值，自动繁殖成上千条新示范。花一份钱吃一千份饭，被后续无数工作沿用——**典型的"没有 GPU 也能想出来"的顶会 idea**
- RoboCasa：大规模厨房场景程序化生成
- 世界模型合成（GR00T-Dreams / Cosmos）：视频生成模型"想象"机器人做任务的视频再反推动作（M5.6 世界模型专题细讲）

**人类视频层**
- Ego4D 等第一人称视频：教模型"人类怎么和物体交互"的先验；难点是没有动作标签，只能学表征/意图/affordance

## 四、共享数据集的真相（批判）

OXE 的贡献：证明跨实验室数据混训能涨点（RT-X 比单实验室模型强），确立"数据共享"范式。
但要看清问题：

1. **异构税**：22 种机器人的相机位、坐标系、夹爪、控制频率全不同，"混在一起"本身有负迁移风险，怎么混是门学问
2. **长尾缺失**：数据集里 90% 是"桌面抓取放置"，真实需求（叠衣、插拔、双手协作）严重欠采样
3. **质量黑箱**：失败轨迹、抖动轨迹混在里面，BC 无差别全学（M3.5 Diffusion Policy 专题 Q3 的呼应）
4. **静态快照**：真正的解法可能是**部署飞轮**——机器人上岗边干边采，数据随部署量指数增长。谁先转起飞轮谁赢，这是 2026 年各公司抢落地场景的底层逻辑

## 五、复试级问答

**Q1：机器人数据为什么贵？有哪几条降本路线？**
要点：贵在人力（遥操作实时陪跑）+设备+场地+重置场景。路线：①设备化（UMI 手持夹爪）；②工厂化（AgiBot World 百台并采）；③繁殖化（MimicGen 一变千）；④虚拟化（仿真+世界模型合成）；⑤飞轮化（部署中自动采集）。能报出 5 条路线+代表工作，这题就是送分题。

**Q2：人类视频数据海量却难用，为什么？现在怎么用？**
要点：没有动作标签（不知道关节怎么动的）+ 形态差异（人手≠夹爪）+ 视角混乱。现用法：学视觉表征预训练、学 affordance/交互先验、学任务意图，或用重定向（retargeting）从人手姿态映射到机器人。承认"直接从视频学策略"仍未解决，是加分的诚实。

**Q3：如果给你 100 万预算建机器人数据集，你怎么花？**
开放题，考规划能力。参考框架：先定任务分布（对准长尾而非重复抓取）→ 设备选型（UMI 类低成本采集器×N 优于买一台贵机器人）→ 质量控制流程（标注成功/失败、剔除抖动）→ 留 20% 预算做数据管理工具。答出"任务分布比数量重要"即高分。

## 工程视角附录

**LeRobotDataset 格式**（事实上的社区标准，复现冲刺天天打交道）：

```text
my_dataset/
├─ data/chunk-000/episode_000000.parquet   # 每帧一行：qpos、action、timestamp
├─ videos/chunk-000/observation.images.cam_high/episode_000000.mp4
└─ meta/
   ├─ info.json          # fps、特征定义（哪些是观测哪些是动作）
   ├─ stats.json         # 归一化统计（M3.4 BC 到 ACT 专题那个坑的源头）
   └─ episodes.jsonl     # 每条轨迹的长度与任务描述
```

**MimicGen 繁殖流水线伪代码**：

```python
demo = load_human_demo()                       # 1 条人类示范
segments = split_by_subtask(demo, object_poses)  # 按"接触哪个物体"切段
for new_scene in randomize_scenes(N=1000):
    for seg in segments:
        seg' = SE3_transform(seg, new_object_pose)   # 随新物体位姿变换轨迹段
    traj = interpolate_and_stitch(segments')          # 段间插值衔接
    if replay_success(traj, sim): dataset.add(traj)   # 仿真回放验证，产出率约 30-70%
```

**常见坑**：
1. 时间戳不同步毁一切：相机 30Hz、控制 50Hz，必须显式对齐插值
2. 夹爪动作表示（二值开合 vs 连续宽度）不统一，混训后夹爪行为诡异
3. 遥操作示范里的手抖、犹豫、停顿会被 BC 一并学走——采数据时"演示者素质"直接决定策略上限
4. 失败轨迹要么滤掉要么显式标注，混入不管 = 给模型喂毒
