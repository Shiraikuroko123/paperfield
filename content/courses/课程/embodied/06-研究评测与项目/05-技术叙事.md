# M6.5 专题：技术叙事

> 使用时机：复试前 3 周。素材：Paperfield、课程专题积累、初试后的复现项目。

## 一、核心原理：叙事 > 清单

平庸自我介绍："我做过 A，还做过 B，也学过 C。"（清单，无记忆点）
你的自我介绍要是**因果链**：每件事是上一件事的必然结果——考官记住的是"这个学生有内驱力和方法论"，而不是零散事实。

## 二、你的故事骨架（三幕）

**第一幕 · 输入系统（动机）**
"我确定要做具身智能后，发现信息过载是第一个障碍——于是我自己开发了 Paperfield，一个聚合 arXiv/DBLP 等来源、带 PDF 精读和问答的论文追踪工作台，用它保持每周精读领域论文的节奏。"
→ 传递信号：工程能力 + 信息素养 + 兴趣是"做出来的"不是"说出来的"

**第二幕 · 动手验证（成长）**
"输入不等于能力，所以初试结束后我立刻做了复现：在 LIBERO 上复现 ACT 和 Diffusion Policy，[你的具体发现，例：发现 DP 在扰动下的失败集中在 X 类场景]，我做了 [你的小改进/分析]，代码开源在 GitHub。"
→ 传递信号：实验手感 + 批判性思维 + 执行力（2.5 个月从考生切换到研究状态）

**第三幕 · 未来投射（规划）**
"这两段经历让我确认了兴趣在 [方向]，读研三年我的计划是研一补全 [短板] 并深度复现，研二做出自己的工作投 CoRL/ICRA——我知道这个节奏可行，因为我已经用同样的方法完成了从零到复现。"
→ 传递信号：规划具体可信，且**用过去的执行为未来背书**（最有说服力的一招）

全篇 90 秒版和 3 分钟版各准备一个，逐字稿写好后发我改。

## 三、Paperfield 的展示策略

- **提前录 2 分钟 demo 视频**（现场网络不可控），手机里备好
- 讲解顺序：痛点（论文过载）→ 一句话方案 → 现场演示精读界面 → 技术栈一句话带过（除非被问）
- 预设追问及答法：
  - "推荐算法怎么做的？" → 如实讲加权筛选逻辑，并主动说局限（"目前是规则加权，我考虑过用 embedding 相似度改进"——展示迭代思维）
  - "和 XX 现成工具比有什么区别？" → 别贬低竞品，讲你的差异定位（本地优先/精读闭环/为具身智能定制的源）
  - "这和科研有什么关系？" → "它是我的科研基础设施，我第 X 课读的论文就是它推给我的"——闭环回故事主线

## 四、高频雷区

1. **吹过头**：把 Paperfield 说成"AI 系统"、把复现说成"研究成果"——考官一追问就穿帮，诚实定位反而显自信
2. **技术细节失控**：自我介绍里堆术语；正确做法是留钩子等考官问（钩子留在你最熟的地方）
3. **贬低本科/初试经历**："我二战所以时间不多"→ 改成"备考期间我用每周固定时间保持领域跟进，初试后全职投入"——同一事实，叙事完全不同
4. **规划假大空**："我要发顶会"→ 改成具体路径（复现什么、几月投什么会）
