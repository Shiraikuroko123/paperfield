# M6.2 专题：评测危机

> 锚点：LIBERO、SimplerEnv；本课是批判性思维专项训练，前面埋的钩子在这里收网

## 一、具身智能评测为什么天然困难

NLP 有 MMLU，视觉有 ImageNet，具身智能没有公认的"那一个" benchmark。因为：

1. **真机不可复现**：你的实验室和我的实验室，光照、桌面、物体、机器人磨损都不同——同一模型两地成功率可差几十个点
2. **成功率是高方差统计量**：每任务只测 10-20 次（真机太贵），±2 次成败就是 ±10-20%，但论文很少报置信区间
3. **泛化无定义**："没见过的物体"——多没见过算没见过？换个颜色 vs 换个类别 vs 换个场景，难度天差地别，全凭作者自由裁量
4. **Demo 文化**：官方视频只放成功案例；π0、各人形公司的惊艳 demo 均无第三方可验证的成功率（M3.6 π0 与 flow matching 专题钩子收网）

## 二、现有 benchmark 地图

| Benchmark | 是什么 | 强项 | 弱点 |
|---|---|---|---|
| **LIBERO** | 仿真操作套件，四个维度分套（空间/物体/目标/长时序），程序化生成 | 维度拆解清晰，可复现，单卡能跑 → **你复现冲刺的主场** | 视觉简单，与真机相关性存疑 |
| **SimplerEnv** | 用仿真复刻真机评测场景，验证"仿真排名≈真机排名" | 直击可复现痛点，评 VLA 主流选择 | 覆盖任务少 |
| CALVIN | 语言条件长时序操作 | 长时序+语言 | 场景单一 |
| RoboCasa | 大规模厨房场景 | 场景丰富度 | 太大，算力门槛 |
| 真机赛事/第三方评测 | 如各类机器人挑战赛 | 最真实 | 昂贵、不可频繁 |

记住格局：**仿真 benchmark 管"可复现的相对比较"，真机 demo 管"可能性证明"，两者都不是"绝对能力度量"**——目前不存在后者。

## 三、读论文时的防骗清单（终身受用）

看到"成功率 95%"先问八个问题：

1. 测了多少次？有没有置信区间？
2. 任务是作者自选的还是公共 benchmark？
3. "没见过"的测试项，训练分布到底覆盖到哪？（语义泛化还是像素级换皮）
4. baseline 是认真调过的吗？（弱 baseline 是最常见的注水术）
5. 失败案例分析在哪？（没有失败分析的论文，成功率先打七折）
6. 视频是挑的还是连续录制？
7. 换个实验室能复现吗？开源了什么？
8. 提升来自方法还是来自更多数据/算力？（消融是否干净）

这份清单同时是你自己写论文时的自查表——**评审就是这么审你的**。

## 四、评测本身是研究机会（低算力金矿）

评测类工作不需要训练大模型，却是顶会常客：SimplerEnv 型（真仿相关性研究）、失败模式分类学、鲁棒性压力测试（光照/干扰物/指令改写扰动下 VLA 掉多少点）、数据污染检测。**给你划重点：这是"没有 GPU 的人做出顶会工作"的最短路径之一，你 12 月的冲刺如果找不到 idea，就从"系统性压力测试开源 VLA"入手。**

## 五、复试级问答

**Q1：为什么说具身智能存在评测危机？**
要点：不可复现（真机环境不可控）+ 高方差小样本 + 泛化无定义 + demo 文化。升华：领域进步速度看起来快，但**没有可信的进度条**，部分"进步"可能是评测自由度的产物。

**Q2：LIBERO 和 SimplerEnv 各解决什么问题？**
要点：LIBERO——把"泛化"拆成四个可控维度做可复现的仿真比较；SimplerEnv——回答"仿真评测能否代理真机评测"（做真仿排名相关性）。一句话：前者管拆解，后者管效度。

**Q3：如果让你设计一个更好的 VLA 评测，你会加什么？**
参考弹药（答两三条即可）：①强制置信区间与最低测试次数；②对抗性扰动套件（干扰物、指令同义改写、光照）；③失败模式自动归类（感知错/规划错/执行错）；④真仿混合分层评测；⑤防污染协议（测试物体/场景对训练保密）。这题答好了，考官会记住你。

## 工程视角附录

**成功率置信区间——必须会算的一个公式**：

对大样本的简单正态近似，点估计、标准误和 95% 区间分别为

$$
\hat p=\frac{k}{n},\qquad
\operatorname{SE}(\hat p)=\sqrt{\frac{\hat p(1-\hat p)}{n}},\qquad
\hat p\pm1.96\,\operatorname{SE}(\hat p).
$$

```python
p = k / n                                  # n 次评测成功 k 次
ci95 = 1.96 * sqrt(p * (1-p) / n)
# n=20, p=0.8  → ±17.5%   ← 20 次评测说"80% 比 75% 强"= 纯噪声
# n=50, p=0.8  → ±11.1%
# n=200, p=0.8 → ±5.5%    ← 这是单个比例的近似区间，仍不足以证明 80% > 75%
# 独立两组比较 0.80 vs 0.75，在双侧 α=.05、power=.80 的近似下约需 1094 次/组
```

上面是正态近似；小样本或成功率接近 0/1 时优先使用 Wilson 区间。比较两个方法时，两组都有抽样误差，不能拿单个比例的区间半宽直接当样本量结论。

**LIBERO 标准评测姿势**：4 个 suite × 每 suite 10 任务 × 每任务 ≥50 rollout，固定 seed 集合，报均值±标准差；对比方法在**同一协议下重跑**，不许直接抄原论文数字（env 版本不同结果不可比）。

**常见坑**（写论文=别人防你，读论文=你防别人）：
1. checkpoint 选择偏差：报"最后一个 ckpt"还是"验证最好的 ckpt"必须声明——后者是隐性过拟合测试集
2. 仿真器版本/物理步长变动，前后结果不可比；环境版本写进论文附录
3. 有些仿真器渲染与物理耦合，开关渲染会改变物理结果——评测配置全程锁死
4. 多 seed 训练（≥3 个训练 seed）比多 rollout 更贵但更诚实：策略性能对训练随机性的方差往往大于评测方差
