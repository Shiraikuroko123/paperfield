# 附录 A：习题参考答案

> 先独立作答。答案给出判断边界，不是唯一措辞；设计题应结合具体机器人、任务和约束。

## M0.1 主干

1. 相同二维图像可能对应不同深度、遮挡后的状态、速度、接触力和历史，因此不足以唯一确定状态。
2. 敏感性取决于低层接口、模型误差和任务。力矩命令通常安全裕度最低；位置命令接触时可能产生大力；末端位姿还依赖 IK、标定和控制器，不能脱离系统比较。
3. 合格图应包含目标分解、传感器、感知/状态估计、策略、动作安全层、控制器、执行器和完成/失败反馈。
4. 示例：“四周内实现二维臂 FK/IK+PD，100 个固定目标中 95 个在 2 秒内达到 2 cm，输出代码、测试和失败报告。”

## M1.1 主干

1. $Ax$ 有定义，结果为 $4\times1$；$x^\mathsf{T}A$ 为 $1\times3$ 乘 $4\times3$，中间维不匹配，无定义。
2. 旋转保持内积，故 $R^\mathsf{T}R=I$，两边关系给出 $R^{-1}=R^\mathsf{T}$。
3. 与动作同形状，为 7 维向量。
4. 步长越过局部稳定区域，在最优点两侧反复过冲；也应检查梯度尺度和数值异常。
5. 不能。点估计为 100%，有限样本仍允许非零失败率；0/20 失败的 95% 失败率上界粗略约 15%。

## M1.2 主干

1. `eval()` 切换层行为；`no_grad()` 关闭计算图记录。验证时通常都需要。
2. 同一 episode 相邻帧高度相关，跨集合会泄漏场景和轨迹信息并夸大泛化。
3. 数据/标签、模型连接与形状、损失、优化与梯度。
4. 反归一化决定真实动作幅度；统计不一致时权重相同也会输出错误物理命令。
5. 不能。差异可能来自训练随机性和评测噪声，需要多 seed、相同协议和不确定性。

## M1.3 主干

1. 三维投影到二维丢失深度；同一像素射线上有无数三维点。
2. $128\times128$；若有 batch/head 维，则通常为 $[B,H,128,128]$。
3. 它会交换左右几何，却未必同步修改语言、坐标和动作标签。
4. 自回归逐项条件生成；扩散从噪声迭代去噪；flow matching 积分学习到的速度场。
5. 一次大模型推理可输出一整块高频动作，低层按高频执行；二者调用次数不同。

## M2.1 主干

1. 把 camera 坐标中的量变到 base；逆矩阵把 base 量变到 camera。
2. 三维旋转不可交换，欧拉角还依赖轴顺序；分量相加通常不等于旋转组合。
3. 肘上、肘下配置可具有同一末端位置。
4. 不能。还需检查碰撞、路径连续性、关节/速度限制和动力学。
5. 奇异附近直接逆会产生巨大关节速度；阻尼限制放大，代价是末端跟踪误差。

## M2.2 主干

1. 更大 P 增强纠错，也增加过冲并降低相位/稳定裕度；延迟和离散采样会进一步恶化。
2. 位置控制强制追位姿；阻抗控制定义位姿误差与力的柔顺关系，更适合接触。
3. 不一定。高层位置通常进入固件 PD/轨迹控制，最终执行器施加电流/力矩。
4. 20 ms；不一定，采集、传输、预处理、安全检查、总线和电机响应也占预算，并有抖动。
5. 裁剪表示策略频繁提出不可执行/危险动作，也改变了实际策略行为。

## M2.3 主干

1. 热和结构限制决定持续能力；峰值只能短时输出。
2. 速度常由位置差分得到，会放大量化噪声和时间抖动。
3. 观测与动作错配，模型可能把动作后果当动作条件或学到相位滞后。
4. 最后速度命令可能让机器人持续运动；应超时进入制动或安全状态。
5. 应覆盖机械隔离/限位、独立急停、电流温度保护、软件裁剪碰撞、分阶段低速测试与日志。

## M2.4 主干

1. 二维框不提供精确深度、姿态、遮挡与可抓区域。
2. 滤波器降低对测量的信任，更依赖过程模型，估计更平滑但可能滞后。
3. 机器人在运动；使用错误时刻位姿会产生系统性空间偏差。
4. 旧图像排队导致控制使用过期观测，延迟不断增加。
5. 物理步是积分周期；控制步是控制器更新周期；策略步是学习策略重新输出的周期。

## M3.1 主干

1. 奖励是一步反馈；回报是从当前起累计的折扣奖励。
2. 行为可由探索策略产生，更新目标却朝向贪心最优动作。
3. 减去只依赖状态的 baseline 不改变梯度期望，却减少回报共同波动。
4. 限制样本上概率比带来的更新收益，改善稳定性；不严格保证 KL、性能或参数变化有界。
5. 价值函数没见过这些动作，函数外推误差可能被策略主动利用。
6. 奖励漏洞、成功判据与奖励不一致、约束惩罚权重变化、课程分布变化、终止利用或实现错误均可能。

## M3.3 主干

1. 它只测专家状态分布，部署状态由学习策略自身动作产生。
2. 主要改变训练状态分布；基础 DAgger 不要求新模型结构。
3. 不必然。每步重预测并集成时仍频繁推理；整块开环执行才显著减少次数。
4. MSE 对应条件均值；L1 对应条件中位数。
5. 相邻重规划可能从不同模式采样，缺少历史承诺和任务级一致性。
6. 数据、视觉底座、观测历史、动作 horizon、训练预算、重规划协议、归一化、参数量和评测种子。

## M4.1 主干

1. IK 输出目标配置；路径规划输出无碰路径；轨迹生成附加时间；控制器输出执行器命令。
2. 抓取需支持后续放置、倒水、插入，并满足可达与视野。
3. 视觉覆盖范围大但局部精度有限；力觉在接触后能检测偏差并柔顺搜索。
4. 标定、状态估计、低层控制、安全、完成检测、恢复、通信和日志。
5. 多步成功近似连乘，错误还会改变后续状态并产生相关失败。

## M4.2 主干

1. 单位的信息密度和时长不同，不能把计数差直接解释为监督量或能力差。
2. 可提前发现坐标、单位、方向、夹爪和延迟错误，这些错误常不影响训练 loss 下降。
3. 可能使用动作发生后的观测预测动作，形成未来信息泄漏，或学习错误相位。
4. 新实例、新类别、新外观、新布局上下文、机器人动作训练未见等。
5. 控制总样本量与采样预算，比较混训、只用目标本体和等量附加目标数据，并做本体分组消融。

## M4.4 主干

1. 可迁移对象语义、关系与常识；不会自动迁移机器人坐标、接触动力学、动作定义和高精度控制。
2. token 复用语言架构但有量化/串行延迟；连续生成头表达连续多模态但需要专门采样和动作模块。
3. 动作块可由一次推理生成，再由低层按高频执行。
4. 同型号新实例、训练未见型号、动作维不同但形态相近、完全新形态，难度依次增加。
5. Grounding 还要求状态可行性、能力模型、反馈和失败恢复，不只是视觉语义。
6. 子目标歧义、对象指代漂移、完成条件不一致、更新频率不匹配和信息丢失。

## M5.1 主干

1. 相对运动噪声累计；回环提供跨长时间约束，使后端重新优化整条轨迹。
2. 高估可能让 A* 忽略真正最优路径，失去最优性保证。
3. 机器人有体积；膨胀后才能用点路径表示整机无碰。
4. 语言 grounding、探索、记忆、歧义、语义泛化和指令完成判断。
5. 手臂可达/可操作度、相机视野、底盘定位误差、碰撞、稳定性和后续步骤。

## M5.2 主干

1. 足端接触建立/解除导致动力学模式离散切换，并伴随连续状态演化。
2. 策略可通过不移动来持续获取奖励，避免运动风险和惩罚。
3. 真机不可直接测得的真实摩擦、精确地形、无噪基座速度和接触真值等。
4. 人体与机器人形态/动力学不同，直接映射可能穿地、脚滑、自碰撞或超过关节/驱动限制。
5. 单位任务成本、成功率、能耗、速度、负载、安全、维护、环境改造和多任务复用。

## M5.4 主干

1. 可能是计算/网络时序、电机动力学或传感器时间戳。分别测端到端各段延迟、关节指令响应和观测时间偏移。
2. 分布过宽使任务过难并逼策略保守，且可能包含不现实环境。
3. 图像/几何不包含唯一物理属性；相同外观可对应不同材料和摩擦。
4. 评测更高，因为它必须保持不同策略的真实排序；有噪训练数据有时仍可被过滤或平均。
5. rollout 把预测作为下一步输入，误差使输入逐渐离开训练分布并累积。

## M6.1 主干

1. rollout 只估计一个已训练模型的执行方差；重新训练的初始化、采样和优化方差未被覆盖。
2. 点估计是样本中的最佳单值摘要；区间表达有限样本下与数据相容的真实率范围。
3. 两方法各自有误差，差值标准误来自两组；单比例半宽不是两比例检验，更没有考虑统计功效。
4. 建立因子实验或分步消融：固定数据与底座只换动作头，再固定动作头分别改变数据/底座，并保持预算可比。
5. 选择偏差和测试集过拟合，使最终结果不再是无偏泛化估计。
6. 否则分类会受方法标签和结果驱动，无法一致复核，也容易事后挑有利解释。

## 评分建议

每题按 0-2 分：0 为结论错误或无因果链，1 为结论基本正确，2 为同时说明假设、机制和失效边界。设计题还应给出可观测指标和验收方法。
