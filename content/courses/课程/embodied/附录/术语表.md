# 附录 B：术语表

| 术语 | 准确定义/本教材语境 |
|---|---|
| Action / 动作 | 策略输出的机器人命令；必须指定空间、单位、坐标系和频率 |
| Action chunk | 一次预测的一段未来动作序列 |
| Affordance | 对象或场景在当前智能体能力下支持的行动可能性 |
| BC | Behavior Cloning，把专家观测-动作对当监督数据学习策略 |
| Calibration | 估计传感器、执行器、坐标和时间关系 |
| Configuration | 机器人所有关节变量组成的配置 |
| Control | 根据目标与反馈产生执行器命令的闭环过程 |
| Covariate shift | 训练输入分布与部署输入分布不同 |
| Cross-embodiment | 在不同机器人形态或动作空间之间共享模型/能力 |
| DAgger | 迭代收集当前策略访问状态并由专家标注的数据聚合算法 |
| Domain randomization | 在训练中随机化环境参数以提高迁移鲁棒性 |
| Dynamics | 状态在动作作用下随时间变化的规律 |
| EKF | Extended Kalman Filter，对非线性模型局部线性化的滤波器 |
| Embodiment | 智能体的物理身体、传感器、执行器和动力学约束 |
| End-to-end | 更少手工中间接口地联合学习输入到输出；不代表系统只有一个模块 |
| Episode | 从初始化到终止的一次完整交互 |
| Flow matching | 学习连续速度场，将基分布运输到数据分布的生成方法 |
| Forward kinematics | 已知关节配置求末端位姿 |
| Grounding | 把符号/语言与当前物理状态、对象和可执行能力对齐 |
| Homogeneous transform | 用 `4x4` 矩阵统一表示三维旋转和平移 |
| IK | Inverse Kinematics，已知末端目标求关节配置 |
| Impedance control | 让末端误差与接触力呈期望弹簧阻尼关系的控制方式 |
| Jacobian | 向量输出对向量输入的偏导矩阵；机器人中连接关节和末端速度 |
| Latency | 从测量产生到动作生效的端到端时间，不只是模型前向时间 |
| Localization | 在已有地图中估计机器人位姿 |
| Loco-manipulation | 移动/行走与操作耦合的全身任务 |
| MDP | 由状态、动作、转移、奖励和折扣组成的决策过程 |
| Mocap | Motion capture，人体或物体动作捕捉数据 |
| MPC | Model Predictive Control，滚动求解有限时域约束优化 |
| Observation | 传感器可获得的信息，通常是状态的带噪、不完整映射 |
| Odometry | 由相邻运动测量累计估计位姿，通常存在漂移 |
| Offline RL | 只用固定数据集学习策略的强化学习 |
| On-policy | 主要用当前策略采集的数据更新当前策略 |
| POMDP | 状态不能由当前观测完全确定的决策过程 |
| Policy | 从观测/状态和任务条件到动作分布的映射 |
| PPO | 使用裁剪 surrogate objective 的 on-policy actor-critic 算法族 |
| Proprioception | 关节、基座、力矩等机器人自身状态感知 |
| Retargeting | 把人或另一机器人的动作映射到目标机器人 |
| Reward | 强化学习中对一步转移的标量反馈，不等于长期回报 |
| ROS2 | 面向机器人分布式模块通信和工具生态的中间件 |
| Rollout | 策略在环境中闭环执行产生的一条交互轨迹 |
| SE(3) | 三维刚体旋转和平移构成的特殊欧氏群 |
| Sim2Real | 从仿真训练/验证到真实系统部署的迁移问题 |
| SLAM | 同时定位与建图 |
| State | 对未来转移足够的环境变量；真实系统通常不能完全观测 |
| System identification | 从输入输出数据估计动力学参数或模型 |
| Teleoperation | 人通过主从设备、VR 等远程控制机器人采集示范 |
| Temporal ensembling | 融合不同历史预测对同一当前动作的估计 |
| Trajectory | 带时间顺序的状态/观测、动作和奖励序列 |
| VLA | Vision-Language-Action，输入视觉/语言并输出机器人动作的模型 |
| VLM | Vision-Language Model，联合处理视觉和语言的模型 |
| World model | 预测状态或观测如何随动作演化的模型 |
| Zero-shot | 未对所声明目标条件额外训练/适配；必须明确“未见”的维度 |
