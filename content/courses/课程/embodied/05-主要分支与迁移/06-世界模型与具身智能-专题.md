# M5.6 专题：世界模型与具身智能

> 锚点：Genie 系列（DeepMind）、Cosmos（NVIDIA）；前置：M4.3 数据问题专题数据金字塔

## 一、什么是世界模型（一句话+一个公式）

**世界模型 = 学会预测"我做了动作 a，世界会变成什么样"的模型**：p(下一观测 | 历史观测, 动作)。

人类开车变道前会在脑内预演——那就是你的世界模型在推理。给机器装上它，三件大事就有了新解法：

1. **数据**：让模型"做梦"生成无限训练数据（攻击第一瓶颈）
2. **评测**：在梦里测策略，不用真机（便宜、安全、可复现）
3. **规划**：在梦里试错找最优动作（model-based RL 的复兴）

2026 年共识："世界模型供数据与环境，VLA 供策略"的闭环是主流叙事——这句话你在我的路线图里见过，现在你懂它的含义了。

## 二、Genie 系列：从视频里学出"可玩的世界"

DeepMind 的路线，惊艳之处在于**无监督**：只用海量互联网视频（无动作标签），模型自己学出"潜在动作空间"——它发现视频里的变化可以用少量离散"动作"解释（前进、跳……），于是学会了"给我一帧图+一个动作，我生成下一帧"。

- Genie 1/2：图生可交互 2D/3D 世界
- Genie 3（2025）：**实时**可交互、分钟级一致性的生成世界——你走过去再回头，场景还在（记忆一致性是世界模型最难的坎之一）

对具身智能的意义：互联网视频（金字塔第三层）第一次变成了"可交互训练场"，而不只是表征学习的原料。

## 三、Cosmos：给物理 AI 造的世界基础模型

NVIDIA 路线，更工程化：Cosmos 是**面向物理 AI 的世界基础模型家族**（文/图/视频 → 物理合理的视频），核心用途：

- **合成数据工厂**：GR00T-Dreams 用它生成机器人执行新任务的视频，再从视频反推动作标签 → 变成训练数据（M4.6 跨本体专题 GR00T 的数据来源闭环）
- **数字孪生增强**：真实场景重建 + 世界模型补全变化（光照、物体摆放）
- **策略评测**：2026 年的 DreamZero / Cosmos Policy 等工作直接在世界模型里评估甚至训练策略

## 四、批判（复试杀手锏）

1. **物理保真度**：视频"看着合理"≠物理正确——接触、摩擦、液体、布料的动力学，生成模型经常做梦式糊弄；用失真数据训策略会学出失真行为
2. **幻觉即毒药**：世界模型幻觉生成的"成功轨迹"混入训练集，是数据污染的新形态
3. **梦里评测的效度**：梦中排名与真机排名是否一致？（real-to-dream 相关性）尚无定论——评测危机的新战场
4. **算力饕餮**：视频生成级的训练与推理成本，比 VLA 本身还贵；学界只能用现成模型，做不了底座
5. **和传统仿真器的关系没理清**：物理引擎（MuJoCo）准但窄，世界模型广但糊；混合方案（引擎管物理、生成模型管外观）可能才是终局

## 五、复试级问答

**Q1：世界模型解决具身智能的什么问题？三条用途各举一例。**
要点：数据（GR00T-Dreams 合成训练数据）、评测（世界模型内测策略）、规划（脑内预演选动作，Dreamer 传统）。加分：指出三条用途对保真度的要求不同——做数据要求最低（有噪声可容忍），做评测要求最高（排名必须与真实一致）。

**Q2：Genie 的"潜在动作"是什么？为什么了不起？**
要点：从无动作标签的视频中无监督地归纳出离散动作词表（模型自己发现"世界的变化由少数可控因素驱动"）。了不起在于绕开了"视频没有动作标签"这个人类视频层的核心障碍（M4.3 数据问题专题 Q2 呼应）。局限：潜在动作≠机器人可执行的关节动作，落到真机还有映射鸿沟。

**Q3：世界模型会取代 MuJoCo/Isaac 这类物理仿真器吗？**
要点：短期不会，互补——引擎：物理准、可控、快，但场景/外观贫乏、长尾行为造不出；世界模型：视觉真实、场景无限，但物理不可靠、不可控、慢。趋势是杂交：real2sim 重建几何 + 引擎跑物理 + 生成模型补外观纹理（GaussGym 是这个方向的例子，M5.5 Sim2Real 专题见）。答"互补+杂交"并给出理由即满分。

## 工程视角附录

**最小世界模型玩具实验**（CPU 可跑，初试后想练手的第一个项目候选）：

潜空间一步预测与重建目标为

$$
z_t=E(o_t),\qquad
\hat z_{t+1}=F_\theta(z_t,a_t),\qquad
\mathcal{L}(\theta)=\left\lVert D(\hat z_{t+1})-o_{t+1}\right\rVert_2^2.
$$

```python
# 移动方块视频的 next-frame 预测
latent = encoder(observation)            # CNN 压到潜空间
next_latent = dynamics(latent, action)   # 潜空间里做动力学
prediction = decoder(next_latent)
loss = mse_loss(prediction, next_observation)
# 关键评测：不是单步误差，是自回归 rollout——
# 用自己的预测当输入连续预测 50 步，看第几步开始崩
```

这个玩具实验教会你世界模型的核心痛点：**teacher forcing 下指标漂亮 ≠ 自回归 rollout 不漂移**——所有世界模型论文的 rollout 曲线都在跟这个问题搏斗。

**用现成大模型**：Cosmos 开源权重可下载做推理（文/图生成物理场景视频），微调是集群级的活，学界玩法是"用它生成→过滤→当训练数据"。

**常见坑**：
1. 报告单步 MSE 不报 rollout 曲线 = 论文防骗清单新条目（M6.2 评测危机专题工具适用于自己）
2. 生成数据入训练集前必须过滤：动作-画面一致性检查（画面里机器人动了，动作标签却是静止？扔）
3. "梦里评测"的结论必须配一次真实环境相关性验证，否则只是自嗨
