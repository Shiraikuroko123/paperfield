# M5.5 专题：Sim2Real

> 锚点：Humanoid-Gym（zero-shot 案例）、GaussGym（real2sim 新范式）；前置：M3.2 RL 与运动控制专题 DR

## 一、把"差距"拆开看（复试画图题）

Sim2Real gap 不是一个差距，是三个：

| 差距类型 | 内容 | 主要受害者 |
|---|---|---|
| **动力学差距** | 摩擦、质量、电机响应、通信延迟与仿真不符 | 运动控制 |
| **感知差距** | 渲染图像 vs 真实相机（光照、纹理、噪点） | 视觉策略 |
| **场景差距** | 仿真场景太干净太少样，真实世界又乱又长尾 | 所有任务 |

诊断口诀：真机失败先问是哪个差距——腿软了是动力学，认错物体是感知，没见过这种桌子是场景。

## 二、工具箱（按差距对症下药)

**动力学差距**
- 域随机化 DR（M3.2 RL 与运动控制专题）：暴力覆盖，代价是保守
- 系统辨识（SysID）：实测真机参数校准仿真，精准但费工
- Teacher-Student / RMA：从本体感受历史在线推断当前动力学并适应
- 实践共识：**三者叠加用**。Humanoid-Gym 的 zero-shot 人形迁移 = 精细 DR + 结构化奖励 + 双仿真器交叉验证（Isaac 训练 → MuJoCo 验证，两个引擎都能跑通再上真机，用"仿真间差距"预演"仿真-真实差距"——这个 trick 值得记住）

**感知差距**
- 视觉 DR：随机纹理光照（经典但糙）
- 高保真渲染（Isaac 的光追）
- 中间表示解耦：策略不吃原始像素，吃深度图/分割/点云——把感知差距推给更成熟的视觉模型扛

**场景差距 → Real2Sim（近年最活跃）**
- 思路反转：与其在仿真里造世界，不如**把真实世界搬进仿真**
- **GaussGym**（ICLR 2026）：手机扫真实场景 → 3D Gaussian Splatting 重建 → 挂上物理引擎 → 机器人在"照片级真实的自家楼道"里训练视觉行走。感知差距和场景差距一起消
- 数字孪生 + 世界模型补全（M5.6 世界模型专题的杂交方案）

## 三、操作任务的 Sim2Real 为什么更难（诚实区）

运动控制的 zero-shot 已常态化，操作没有。原因：①接触物理——抓握的接触点力学，仿真器至今算不准；②软物体——布料液体食物，物理引擎的软肋；③毫米级精度要求放大一切误差。所以操作领域的主流仍是**真机示范**（第 02、06 课的存在理由）+ 仿真只做预训练/数据增广。**"操作的 Sim2Real"是公认的高价值未解题**——记住这句，复试谈开放问题用得上。

## 四、批判（复试杀手锏）

1. DR 的哲学缺陷：承认仿真不准，用"更大的不准"覆盖——治标；SysID/Real2Sim 才是治本方向，但成本高
2. Real2Sim 的死角：重建的是几何与外观，**物理属性（质量、摩擦）扫描不出来**，还得靠估计
3. Zero-shot 是宣传词：论文的 zero-shot 通常经历了大量真机失败迭代 DR 范围的"隐性调参"，只是最终版没微调
4. 评测缺失：Sim2Real 成功与否只看"真机能不能跑"，缺乏"差距大小"的量化度量——研究机会

## 五、复试级问答

**Q1：把 Sim2Real gap 分类，并各给一个对策。**
要点：动力学（DR+SysID+在线适应）、感知（视觉DR/中间表示解耦）、场景（Real2Sim 重建）。答出"先诊断哪类差距再选工具"的思路即高分，报出 GaussGym 这种 2026 新工作是加分弹药。

**Q2：为什么运动控制 zero-shot 成熟而操作没有？**
要点：运动依赖的刚体+地面接触仿真较准、误差容忍度高（步态差点也能走）；操作依赖的抓握接触/软物体仿真失真、毫米级精度容忍度低。深层：**仿真保真度的天花板决定了 RL 路线在各任务上的边界**——这句话把M3.2 RL 与运动控制专题的表格升华成了原理。

**Q3：给你一台真机和一个仿真训好的策略，部署失败了，你的调试流程？**
考工程思维：①录真机数据回放对比仿真轨迹，定位差距类型；②动力学差距→SysID 校准或扩 DR 范围重训；③感知差距→检查相机标定、试中间表示；④场景差距→采集失败场景加入训练。答出"系统性二分定位而不是乱试"就赢了大多数应试者。

## 工程视角附录

**上真机前 checklist**（工业界真实流程的学术简化版）：

```text
□ 全链路延迟实测：观测采集→推理→动作执行（常见 20-60ms），
  并把同量延迟注入仿真重训/验证        ← 最常被忘，排第一
□ PD 增益对齐：仿真 stiffness/damping 与真机固件参数一致
□ 观测逐项对拍：真机摆同一姿态，每个观测量与仿真数值差 <5%
  （单位错误、坐标系方向、四元数顺序 wxyz/xyzw 都在这步现形）
□ 动作限幅 + 软急停先写好再谈别的
□ 双仿真器验证：Isaac 训 → MuJoCo 测，掉点 >20% 说明过拟合了训练引擎的物理
```

**SysID 最小流程**：真机执行 chirp（扫频）指令 → 记录关节响应 → 在仿真里优化摩擦/阻尼/电机常数拟合响应曲线 → 校准后的仿真再训练。一天能做完，收益常大于扩大 DR 范围。

**常见坑**：
1. 大家都盯着摩擦系数调，**真正的杀手通常是延迟和电机模型**
2. 视觉策略：真机相机的自动曝光/白平衡不锁定，光照一变全完
3. DR 范围当超参乱扩：范围翻倍 ≠ 更鲁棒，可能直接学不会
4. "真机成功"要定义清楚：连续 10 次成功 8 次，和录像里成功 1 次，是两种人生
