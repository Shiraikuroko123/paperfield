# M5.2 主干：运动控制与人形机器人

## 学习目标

学完本章，你应能定义腿式运动控制的观测、动作和奖励，理解并行 RL、特权学习、域随机化和动作跟踪，解释全身控制与 loco-manipulation，并对人形形态的收益和成本作技术判断。

## 14.1 腿式系统为什么难

腿式机器人是欠驱动、混杂动力学系统：足端接触会建立和解除，身体可能腾空，地面冲击和摩擦决定是否滑倒。人形重心高、支撑区域小、自由度多，上肢动作还会扰动平衡。

核心状态可能包含：基座姿态与速度、关节位置/速度、足端接触、地形和命令。真实系统无法精确测得所有量，需要状态估计。

## 14.2 分层控制

传统结构可能包含：

```text
步态/落脚规划
-> 质心与接触力优化
-> 全身逆动力学
-> 关节力矩控制
```

学习结构常让策略输出目标关节位置或力矩，外层仍保留 PD、状态估计和安全保护。学习控制与经典控制经常混合，而不是二选一。

## 14.3 RL 训练定义

典型命令跟踪任务：

- 观测：重力方向、关节状态、历史动作、命令，可选高度图/视觉。
- 动作：关节目标偏移或力矩。
- 奖励：线/角速度跟踪、姿态、足端、平滑、能耗、碰撞。
- 终止：跌倒、越界、严重碰撞。

高吞吐并行仿真能缩短墙钟时间，但不能消除奖励漏洞、训练方差和仿真假设。

## 14.4 奖励与涌现行为

奖励项之间会产生意外行为：

- 存活奖励过强 -> 站着不走。
- 能耗惩罚过强 -> 拒绝抬脚。
- 速度跟踪过强 -> 通过高冲击跳跃追命令。
- 足端高度奖励 -> 夸张抬腿。

每项应记录分量曲线并做消融。动作自然度不能只凭精选视频，需考虑 jerk、冲击、能耗、周期性和人类评价。

## 14.5 特权学习与适应

训练时 teacher 可访问真实地形、摩擦、质量和接触等仿真特权信息；部署 student 只能用真机可得观测。student 可从历史推断隐藏动力学或直接模仿 teacher。

这类方法能提高训练和适应，但要防止 student 输入中意外残留真机不可得变量。历史长度、延迟和噪声也必须按真机条件训练。

## 14.6 域随机化

常随机化：

- 质量、质心、摩擦、关节阻尼；
- 电机强度、PD 增益、动作延迟；
- 地形、外力推扰；
- IMU/编码器噪声和偏置。

随机化范围应来自设备规格、系统辨识和真机失败。最终策略在平均性能和最坏情况鲁棒性之间存在权衡。

## 14.7 感知式运动

纯本体策略无法提前看到台阶和沟壑。加入高度图、深度或视觉后出现新问题：遮挡、延迟、外参、深度噪声和过时地图。

常见结构用地形编码器产生局部表示，与本体状态融合。失去视觉时系统应能降级到安全步态或停止。

## 14.8 动作跟踪与重定向

Mocap/人类视频提供全身动作先验：

```text
人体动作
-> 骨架/关键点估计
-> retarget 到机器人
-> 清理穿地、脚滑、自碰撞
-> RL 跟踪并保持平衡
-> 蒸馏/部署
```

人和机器人比例、关节范围、质量与驱动能力不同，重定向不是简单复制角度。参考动作物理不可行会限制策略上限。

Reference State Initialization 让策略从轨迹不同阶段开始训练；早期终止防止摔倒后无意义采样。两者会改变初始状态和训练分布，需在报告中说明。

## 14.9 全身控制与 loco-manipulation

拿重物、弯腰、推车时，上肢目标会改变质心和接触力，不能把“腿保持平衡”和“手独立操作”完全分开。

方案包括：

- 全身优化控制，显式处理接触和动力学；
- 运动技能库与混合；
- 动作跟踪底座 + 高层末端目标；
- 联合 RL/VLA 策略；
- 上层规划、全身控制器和手部策略分层。

评测除任务成功外，应报告跌倒、支撑变化、接触力、负载、能耗和恢复。

## 14.10 人形是不是必要形态

技术收益：人类环境中的楼梯、门把、工具和工位按人体设计；统一形态可能共享数据和工具。

技术成本：双足稳定、能耗、安全、价格、维护、负载和控制复杂度。许多受限任务用轮式底盘+双臂更可靠。

结论应依任务和部署条件，而不是“人形一定是终局”或“人形都是伪需求”。需要比较单位任务成本、可靠性和环境改造成本。

## 14.11 上真机检查

1. 对齐关节方向、零位、PD、动作尺度和频率。
2. 在仿真注入实测延迟、噪声和电机限制。
3. 第二仿真器或扰动集测试，检查对单一引擎过拟合。
4. 吊架、低增益、低动作尺度和急停。
5. 先站立，后小命令，再逐步扩大地形和速度。
6. 记录限幅、温度、通信抖动、跌倒与人工干预。
