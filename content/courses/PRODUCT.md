# Product

## Register

brand

## Users

具备电子信息、软件工程、视觉系统或机器人项目基础，希望系统补齐 LLM 与现代机器人学习知识链的中文学习者。他们会在桌面端连续精读，也会在移动端查术语、复习章节和确认课程顺序。

## Product Purpose

把 LLM 系统课程与具身智能课程整合成一个公开、稳定、可搜索的在线教材。成功意味着读者从唯一入口即可选择路线、理解模块顺序、跨课程检索概念、连续阅读章节并运行实验。

## Brand Personality

冷静、机械、研究导向。视觉像一份长期使用的实验室手册：索引鲜明、证据优先、没有营销噪声。

## Design Principles

1. 两条路线清楚分离，但共享导航、搜索与阅读规则。
2. 课程结构、实验、公式和参考资料先于装饰。
3. 正文保持适合长时间阅读的字号、行长与段落节奏。
4. 桌面端适合连续精读，移动端适合检索、复习和确认顺序。
5. 静态构建、公开源码，并由 GitHub Actions 自动发布。

## Accessibility & Inclusion

以 WCAG 2.2 AA 为基线，保证对比度、键盘操作、可见焦点、语义化标题、替代文本、深浅主题和减少动态效果偏好。表格、公式、代码和流程图可独立横向滚动。
